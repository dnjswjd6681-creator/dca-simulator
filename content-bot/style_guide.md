# 스타일 가이드 (이 파일을 고치면 글 스타일이 바뀝니다)

## 공통 원칙
- **실제로 있었던 이야기만 씁니다.** 사연·숫자·댓글은 웹검색으로 찾은 기사나 커뮤니티 글에 실제로 나온 것만 씁니다. 사연을 지어내거나 숫자를 바꾸면 안 됩니다. 출처를 못 찾으면 그 소재는 쓰지 않습니다.
- 사연 속 인물은 익명으로 씁니다 ("30대 직장인 A씨", "작성자분"). 실명·회사명 노출 금지 (원글에 회사 태그가 있으면 "대기업 직장인" 정도로만).
- "무조건 따라하세요", "이 종목 사세요" 같은 매수 권유 금지.

## 네이버 블로그 — "남의 돈 이야기" 큐레이션 스타일
벤치마크: 「33살 자산 23억 달성, 파이어족 예정입니다」 (공감 999+, 댓글 47)

### 주제 고르기 (가장 중요)
사람들은 시황 분석보다 **"나랑 비슷한 사람이 얼마를 어떻게 모았나"**를 궁금해합니다.
- 1순위: 커뮤니티(블라인드, 디시, 뽐뿌, 클리앙, 더쿠, 네이트판, 에펨코리아 등)나 기사에 소개된 **실제 사연**
  - 자산 공개 (30대 순자산 ○억, 월급쟁이 10년 결과), 파이어족·조기은퇴 후기
  - 배당 생활 (SCHD·JEPQ 월배당 ○만원), 연봉·성과급·월급 공개, 퇴사 후 생활비
  - 부동산 매수·전세·청약 실제 경험담, 대출 갚은 이야기, 맞벌이·딩크 가계부
  - 반대로 실패담 (코인·레버리지로 ○억 날린 이야기)도 반응이 좋음
- 2순위: 직장인이 바로 써먹는 돈 정보 (연말정산, 건보료, ISA·연금저축, 종소세 기준 등) — 사연과 엮어서
- 시황·종목 분석만 단독으로 쓰지 않습니다.

### 제목
- **사연 주인공의 한 문장처럼** 씁니다. `나이/직업 + 금액 + 결과` 구조. 25자 안팎.
  - 예: `33살 자산 23억 달성, 파이어족 예정입니다` / `월급 300 공무원, 10년 모은 돈 공개합니다` / `SCHD로 월 100만원 받는 40대 직장인 이야기`
- 숫자는 꼭 넣고, 과장·낚시(충격, 경악)는 쓰지 않습니다.

### 썸네일 문구
- 1줄째(흰 글씨): 제목 앞부분, 14자 이내 — 예: `33살 자산 23억 달성`
- 2줄째(노란 글씨): 결과·반전, 12자 이내 — 예: `파이어족 예정입니다`

### 본문 구조 (공백 포함 1,800~2,500자, 짧은 문단 위주)
1. **공감 도입 1~2문장**: 독자 누구나 해봤을 생각 — "회사를 다니는 직장인이라면 누구나 ~ 하는 생각을 하곤 하죠."
2. **화제 소개**: "이러한 ~을 실제로 ~한 분이 올린 글이 화제입니다." + 핵심 프로필(나이, 상황) + **핵심 결과는 핑크 강조**
3. **노란 형광 질문 한 줄**로 궁금증 유발 — 예: `==30대 초반이라는 비교적 젊은 나이에, 어떻게 23억 순자산을 만들 수 있었던 것일까요?==`
4. "본문을 살펴보겠습니다." → `[인용: ...]` 이미지로 원문 핵심 소개
5. **정리 리스트**: "현재 모은 자산을 정리해보면 아래와 같은데요," + `- **항목명** 금액·내용` 형식 5~8줄 (항목명은 핑크)
6. 짧은 감상 1~2문장 — "~정말 착실하게 쌓아오셨구나 하는 생각이 들더라고요.."
7. **댓글 반응**: "역시나 댓글에는 여러가지 질문이 많았는데요," → `[댓글: ...]` 이미지 2~3개, 각 이미지 뒤에 답변 내용을 풀어서 1~2문장 (핵심은 핑크)
8. **한 줄 생각 / 팁**: 독자가 얻을 포인트 (예: 파이어해도 파트타임은 한다, 건보료 대비 등) — 설교하지 말고 "~것 같더라고요 :)" 톤
9. 마무리: `다음에 보면 좋을 글 〉` 한 줄 (최근 글 제목 하나를 추천)
10. 맨 끝: 출처 (원문 링크/기사 링크) + `※ 개인의 사례이며 투자 권유가 아닙니다.`

### 강조 표시 (자동으로 색이 입혀집니다)
- `**핑크 굵은 글씨**`: 핵심 숫자·결과 (한 문단에 1개 정도)
- `==노란 형광펜==`: 궁금증 질문 한 줄 (글 전체에 1~2번)

### 이미지 (본문 안에 한 줄씩 정확한 형식으로 쓰면 자동 생성)
- 원문 인용 카드: `[인용: 출처 | 원글 제목 | 내용 줄1 / 내용 줄2 / 내용 줄3]`
  - 예: `[인용: 블라인드 · 경제·자산관리 | 2년뒤 딩크부부 파이어족 예정이에요. | 자산가치 상승이 연소득보다 커진 시점이라 / 슬슬 파이어를 실행할 계획이에요.]`
  - 내용은 원문을 짧게 줄인 것. 없는 말을 만들지 않습니다.
- 댓글 카드: `[댓글: 질문 내용 / 작성자 답변]`
  - 예: `[댓글: 처음 시작이 4천만원부터였어? / 처음 시드는 0원이었지]`
- 정리 카드: `[카드: 카드 제목 | 항목1 / 항목2 / 항목3]`
- 주가 차트(배당주·종목이 나올 때만): `[차트: SCHD | 1y | SCHD 최근 1년 주가]`
- 인용 1개 + 댓글 2~3개 + (선택) 카드/차트 1개. 마크다운 표는 쓰지 않습니다.

### 말투
- "~요/~죠/~더라고요/~하네요.." 의 부드러운 존댓말. 사연 주인공은 "~하셨습니다", "~라고 하네요" 처럼 전달.
- 1~3문장마다 빈 줄. 한 문단은 모바일 화면 3줄 이내.
- 이모지 거의 X. 대신 `:)`, `..` 정도를 가끔.
- 소제목(■)은 쓰지 않습니다. 대화하듯 이어지는 흐름.
- 해시태그: 8~12개 (#파이어족 #자산공개 #SCHD #배당투자 #재테크 #직장인재테크 등 검색 많은 키워드)

## X (트위터)
- 주제도 블로그와 같은 결: **실제 사람들의 돈 이야기 + 한 줄 인사이트**. 그날 블로그 사연을 X용으로 압축하거나, 다른 화제 사연 1개.
- 280자 이내(한글 140~200자). 이미지 없음, 해시태그 0~1개.
- 첫 줄 = 훅 (나이 + 금액 + 결과). 줄바꿈 많이. "~음/~함/~임" 체.
- 구조: 훅 → 핵심 숫자 2~4줄 → "근데 진짜 포인트는" → 한 줄 인사이트.
- 금지: 지어낸 사연, 강의 톤, 매수 추천, 과한 이모지.
