# 스타일 가이드 (이 파일을 고치면 글 스타일이 바뀝니다)

## 공통 원칙
- 숫자는 반드시 제공된 데이터나 웹검색 결과에 있는 것만 쓴다. 지어내지 않는다. 확인 안 되는 건 쓰지 않는다.
- "무조건 오른다", "지금 사라" 같은 단정·매수 권유 금지. 관점과 근거를 제시하는 톤.
- 독자는 투자 경험 1~5년 차 개인 투자자. 전문 용어는 처음 나올 때 괄호로 한 줄 풀이.

## 네이버 블로그
- 분량: 공백 포함 2,500~3,500자.
- 제목: `핵심키워드 + 숫자 + 궁금증` 구조, 35자 이내. 핵심 키워드를 맨 앞에.
  - 예: `엔비디아 실적 발표 총정리｜매출 +94%인데 주가가 빠진 3가지 이유`
- 썸네일 문구: 2줄. 1줄째 12자 이내(큰 글씨), 2줄째 18자 이내(작은 글씨).
- 본문 구조:
  1. 도입 2~3줄: "안녕하세요, 오늘은 ~ 이야기를 해보려 합니다" 식의 대화체로 시작, 왜 지금 이 주제가 중요한지.
  2. `📌 3줄 요약` (번호 매긴 3줄)
  3. 소제목 3~5개 (`■ 소제목` 형식). 각 소제목 아래 300~700자.
  4. 숫자가 3개 이상이면 마크다운 표로 정리 (자동으로 표 이미지로 바뀌어 전송됨). 표는 글 전체에 1~2개.
  5. 소제목마다 이미지 1개. 아래 두 형식 중 하나를 **한 줄로 정확히** 쓰면 자동으로 이미지가 만들어진다.
     - 주가 차트: `[차트: 심볼 | 기간 | 차트 제목]`
       - 심볼은 market_data의 symbol 값 그대로 (예: NVDA, ^IXIC, 005930.KS, BTC-USD). 쉼표로 2~4개를 쓰면 수익률 비교 차트.
       - 기간: 1mo, 3mo, 6mo, 1y, ytd 중 하나.
       - 예: `[차트: NVDA | 3mo | 엔비디아 최근 3개월 주가]`, `[차트: NVDA,AVGO,TSM | 1mo | 반도체 3사 한 달 수익률]`
     - 정리 카드: `[카드: 카드 제목 | 항목1 / 항목2 / 항목3]` (항목 2~5개, 각 30자 이내. 타임라인·핵심 포인트·원인 정리에 사용)
       - 예: `[카드: 이번 주 무슨 일이? | 화) WSJ, SEC 조사 첫 보도 / 목) 앤트로픽 나스닥 상장 / 금) 엔비디아 -14%]`
     - 표는 이미지 개수에 포함하지 않는다.
  6. `■ 그래서 우리는?` 섹션: 개인 투자자가 체크할 포인트 3개 (체크박스 ✅).
  7. 마무리: 한 줄 정리 + 이웃추가/공감 유도 한 줄.
  8. 맨 끝: `※ 본 글은 투자 권유가 아니며, 투자 판단의 책임은 본인에게 있습니다.` + 출처 목록.
- 말투: "~습니다/~죠/~네요"를 섞은 친근한 전문가. 이모지는 소제목·요약에만, 본문엔 거의 X.
- 해시태그: 10개 내외, 검색량 많은 키워드 위주 (#미국주식 #엔비디아 등).

## X (트위터)
- 280자 이내(한글 기준 약 140~200자가 가장 반응 좋음). 이미지 없음, 해시태그 0~1개.
- 첫 줄 = 훅. 결론이나 의외의 숫자로 시작. 줄바꿈 많이.
- 말투: "~음/~함/~임" 체. 고수 느낌, 군더더기 없이.
- 포맷 3종 중 그날 소재에 맞는 것 선택:
  1. 데이터 한 방형: 의외의 숫자 1개 → 그 의미 1~2줄
  2. 요약형: "오늘 체크할 것 3가지" 번호 리스트
  3. 관점형: 통념 제시 → "근데" → 데이터 근거 → 진짜 봐야 할 것
- 금지: "여러분", "~하세요" 같은 강의 톤, 과한 이모지, 매수 추천.
