# 📈 블로그·X 초안 자동 생성기

매일 시장 데이터와 뉴스를 모아서 Claude가 초안을 쓰고, 텔레그램으로 보내줍니다.
검토하고 복사해서 올리기만 하면 됩니다.

| 시간 (KST) | 받는 것 |
|---|---|
| 매일 07:07 | 네이버 블로그 글 1개 (썸네일 포함) + X 글 1개 |
| 매일 16:37 | X 글 1개 (국장 마감 후) |

> GitHub 예약 실행은 붐빌 때 10~30분 늦어질 수 있어요.

## 동작 순서
1. **수집**: 미국·한국 지수와 대형주(Yahoo Finance), 환율·금리·유가, 크립토 시세·도미넌스·공포탐욕지수·스테이블코인 발행량(CoinGecko, alternative.me, DefiLlama), 뉴스와 커뮤니티 RSS(CNBC, MarketWatch, 연합뉴스, 한국경제, 매일경제, CoinDesk, Reddit)
2. **작성**: Claude가 데이터를 읽고, 필요하면 웹검색으로 배경을 확인한 뒤 `style_guide.md`대로 글을 씁니다. 주제 비중은 미국주식 60, 국내주식 20, 크립토 20이고, 최근 주제와 겹치지 않게 고릅니다.
3. **썸네일**: 1080×1080 이미지를 자동으로 만듭니다.
4. **전송**: 텔레그램으로 썸네일, 제목, 본문, `.md` 파일, X 글, 출처를 보냅니다.
5. **보관**: `drafts/날짜/` 폴더에 원본이 자동으로 쌓입니다.

## 처음 한 번만 설정하기 (약 15분)

### ① Claude API 키 발급
1. https://console.anthropic.com 에 가입하고 로그인합니다.
2. **Billing**에서 크레딧을 충전합니다. 최소 $5부터 가능하고, 이 정도면 2~3주쯤 씁니다.
3. **API Keys**에서 **Create Key**를 누르고 `sk-ant-...`로 시작하는 키를 복사합니다.

### ② 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather**를 검색해서 대화를 열고 `/newbot`을 보냅니다.
2. 봇 이름과 아이디(`_bot`으로 끝나야 함)를 정하면 **토큰**을 받습니다. `123456:ABC...` 형태예요.
3. 방금 만든 봇과 대화를 열고 아무 메시지나 하나 보냅니다. (안 보내면 봇이 나한테 메시지를 못 보내요.)
4. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates`를 엽니다. 결과에서 `"chat":{"id": 숫자` 부분의 숫자가 **Chat ID**예요.

### ③ GitHub에 키 등록
저장소에서 **Settings → Secrets and variables → Actions → New repository secret**으로 들어가 3개를 등록합니다.

| Name | Value |
|---|---|
| `ANTHROPIC_API_KEY` | ①에서 받은 키 |
| `TELEGRAM_BOT_TOKEN` | ②에서 받은 토큰 |
| `TELEGRAM_CHAT_ID` | ②에서 찾은 숫자 |

### ④ 테스트 실행
**Actions** 탭에서 **content-bot**을 고르고, **Run workflow**에서 `morning`을 선택해 실행합니다. 3~5분 뒤 텔레그램으로 초안이 오면 성공이에요.

## 내 취향대로 바꾸기
- **글 스타일**: `style_guide.md`를 고치면 바로 반영됩니다. 말투, 분량, 제목 공식, X 포맷을 여기서 바꿀 수 있어요.
- **종목, 뉴스 소스, 유튜브 채널, 계정명**: `config.py`
- **보내는 시간**: `.github/workflows/content-bot.yml`의 `cron` 값. UTC 기준이라 한국 시간에서 9시간을 빼야 해요.

## 예상 비용
Claude Opus 5.5 기준으로 하루 약 $0.5~0.8, **한 달 약 2만~3.5만 원**으로 예상합니다. 첫 주 실제 사용량을 보고 조정하세요. 웹검색 횟수에 따라 달라지고, 실제 사용량은 console.anthropic.com의 Usage에서 볼 수 있어요.
아끼고 싶으면 `config.py`에서 `WEB_SEARCH_MAX_USES` 값을 0으로 바꿔 웹검색을 끄거나 `EFFORT = "low"`로 낮추세요. GitHub Actions 실행은 무료예요.

## ⚠️ 주의
- 숫자는 수집한 데이터와 웹검색 결과만 쓰도록 지시해 뒀지만, 올리기 전에 꼭 확인해 주세요. 텔레그램으로 함께 오는 출처 링크를 쓰면 됩니다.
- Reddit RSS 같은 일부 소스는 가끔 막힐 수 있어요. 그래도 나머지 소스로 계속 진행합니다.
